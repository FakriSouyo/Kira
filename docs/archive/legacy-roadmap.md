# Legacy Roadmap

Historical document from the FinHarness era. The current project is Kira. This
document is retired and is not a current architecture authority.

## Status

This roadmap is retired and is not a source of current architectural truth.
Current truth lives in `README.md`, `ARCHITECTURE.md`, `docs/ROADMAP.md`, and
`docs/PROGRESS.md`.

## Historical era

FinHarness originally developed through a Phase 0–9 and addendum planning model.
That era covered the original Evidence-first Bull/Bear/Judge prototype,
Market/News expansion, session/history/export/streaming, early workflow
orchestration, web preview, evidence search and vector prototypes, normalized
data prototypes, and release/distribution hardening.

The detailed tasklists and addendum files were useful while those milestones
were being built, but they are no longer maintained project documentation.

## Why it was retired

The architecture evolved into a canonical Session → Turn → Execution lifecycle,
Context Engine, typed Artifacts, provider-neutral financial data,
VerifiedFinancialSnapshot, and the durable resumability foundation. The living
roadmap is now the A–P architecture lineage, with PR P as the next
same-Execution `/judge` checkpoint/resume milestone.

The old phase model also mixed implementation diary entries, release notes,
design proposals, and source-of-truth claims. Keeping it active would make new
contributors choose between competing descriptions of the current system.

## Historical source

The detailed old documents remain available through Git history. They are not
recreated or copied into this archive.
