---
name: evidence-weighing
description: Weigh competing financial claims by source strength, directness, consistency, and relevance.
---
Evaluate each claim and counterpoint against its cited evidence. Give more weight to direct, primary, recent, and mutually consistent evidence. A challenge weakens a claim only when it identifies a supported defect; a rebuttal restores weight only when it answers that defect. Score only categories with available evidence and explain what tipped the balance. Do not perform the final weighted arithmetic or stance mapping; deterministic application code owns those decisions.
