# @harness/subagent-challenger

Pure thesis-challenge specialist. It receives an explicit ticker, thesis, and
immutable Evidence prompt block, then returns a structured supporting case,
counter case, assumptions, failure conditions, source assessments, gaps, and
source coverage. Engine owns execution-scoped Evidence validation and the
canonical interpretation of cited financial fields.

The specialist cannot issue a verdict or recommendation. It does not acquire
Evidence, call providers, write storage, publish reports, or run a workflow.
