# @harness/subagent-researcher

Pure source-research specialist. It converts an immutable evidence block into cited findings, explicit source-quality assessments, and research gaps. The package owns only its persona, output schema, and mandatory research skills; command packages decide when to invoke it.

There is intentionally no `lib/` or `dist/` directory. Kira is ESM-only and resolves TypeScript source directly in development and tests.
